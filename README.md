# abestudy — アベノミクス期の日本株ポートフォリオ研究

**リポジトリ:** https://github.com/KAFKA2306/abestudy

アベノミクス期を中心とした日本株の日次データを取得し、年次リバランスの平均分散ポートフォリオを計算・可視化する研究プロジェクトです。

過去の構成銘柄と価格だけを使うウォークフォワード分析を目標とし、現在の採用銘柄を過去へ遡って適用する生存者バイアスや、未来情報の混入を避けることを重視します。

## 研究対象

このリポジトリでは、政策期間を次の範囲として扱います。

```text
2012-12-26 〜 2020-09-16
```

市場データは`yfinance`から取得し、日次終値・出来高を分析用YAMLへ保存します。実際に取得できた開始日・終了日・銘柄数は、生成データと各実行ログを正としてください。

## 分析条件

- 対象 — 日本株、主に日経平均採用銘柄
- リバランス — 年次
- 推定窓 — 252取引日
- 最適化 — 平均分散法による最大シャープレシオ候補
- 空売り — なし
- 1銘柄の上限 — 20%
- タイムゾーン — `Asia/Tokyo`
- 出力 — YAMLレポートとSVG図

これらは研究上の設定であり、最適性や実運用可能性を保証するものではありません。

## 実行

```bash
uv sync
uv run python -m src.run_pipeline
uv run python -m src.run_visualization
```

依存関係は`pyproject.toml`に定義されています。

## 処理の流れ

```text
価格・出来高を取得
  → 日付・欠損・銘柄コードを正規化
  → 年ごとの投資ユニバースを決定
  → 過去252取引日から期待収益・共分散を推定
  → 制約付き最適化
  → 翌期間の結果を記録
  → YAMLレポートと図を生成
```

## 主な構成

```text
abestudy/
├── data/raw/             # 取得した市場データ
├── src/data_io/          # YAML入出力
├── src/ingestion/        # データ取得
├── src/analytics/        # 最適化・評価
├── src/reporting/        # レポート生成
├── reports/portfolio/    # 年次ポートフォリオ結果
└── reports/figures/      # 可視化
```

## 情報リーク対策

1. 各年の意思決定時点で利用可能だった構成銘柄を使う
2. 推定期間より後の価格を入力へ含めない
3. ウォークフォワードで訓練期間と評価期間を分離する
4. データ、設定、コードの版を記録する
5. 未来日参照や日付不整合をテストする
6. 欠損銘柄や上場廃止銘柄を黙って除外しない

## 結果の読み方

READMEへ固定値を転記すると、コードやデータ更新後に古くなるため、最新の年率リターン、ボラティリティ、シャープレシオ、最大ドローダウンは`reports/portfolio/`と`reports/figures/`を正とします。

結果を比較するときは、少なくとも次をそろえてください。

- 投資ユニバース
- 無リスク金利
- 取引費用
- リバランス日
- 配当・株式分割の調整
- ベンチマーク
- インサンプル／OOSの区分

## 注意

- 過去データに対する最適化は過学習しやすい手法です
- `yfinance`の値は公式取引所データそのものではありません
- 取引費用、税、流動性、約定制約を含まない場合があります
- 本プロジェクトは投資助言や売買推奨ではありません
