# abestudy — アベノミクス期の日本株ポートフォリオ研究

アベノミクス期を中心に、年次リバランスの日本株ポートフォリオをウォークフォワード評価する研究コードです。

## 現在の状態

**最適化ロジックは監査・修正済みですが、`data/reference/nikkei225_memberships.yaml`の過去時点構成は出典未検証です。既存レポートを歴史的な日経225構成銘柄に基づく結果として使用しないでください。**

価格が存在することは、その時点で日経平均へ採用されていた証拠にはなりません。ユニバーススナップショットを公式のas-of資料と照合するまで、生成結果には`data_quality.snapshot_provenance_verified: false`を記録します。

## 監査で修正した問題

- `LOOKBACK_DAYS=252`を252暦日として扱っていた処理を、意思決定日前の252取引観測へ変更
- `MIN_TRAINING_OBSERVATIONS`が未使用だった問題を修正
- 観測不足銘柄と共通取引日不足を記録付きで除外
- 最大ウェイト制約が実行可能か事前検査
- SLSQP失敗、非有限値、ウェイト合計・上下限制約違反をエラー化
- 最適化結果のクリップ後再正規化による上限超過を廃止
- ウェイト0の欠損銘柄が評価期間全体を消去する問題を修正
- 指定日以前のユニバースがないとき、未来のスナップショットを代用しない
- 除外理由、訓練観測数、評価観測数をレポートへ保存
- 回帰テストを追加

## 分析条件

- 政策期間 — 2012-12-26〜2020-09-16
- リバランス — 年次
- 訓練窓 — 意思決定日前の最大252取引観測
- 最低訓練観測 — 120
- 最適化 — 長期保有・空売りなし・最大シャープレシオ候補
- 1銘柄上限 — 20%
- 評価 — 訓練期間より後の当年リターン
- 価格 — `yfinance`の調整後終値

現在の`annual_return`は日次平均×252の算術年率換算で、CAGRではありません。レポートに`annual_return_method`を記録します。

## 実行

```bash
uv sync

uv run python -m src.run_visualization
python -m unittest discover -s tests -v
```

## 受入条件

結果を採用するには、少なくとも次を満たす必要があります。

1. 各年1月1日時点以前の公式構成銘柄資料へスナップショットを結び付ける
2. 銘柄変更、社名変更、上場廃止、ティッカー変更を時点付きで記録する
3. 訓練窓が評価開始日より前だけで構成されている
4. 最適化が成功し、ウェイト合計1、各銘柄0〜20%を満たす
5. 評価観測数と除外銘柄・理由が保存されている
6. 取引費用、税、配当、流動性を含めたか明記する

## 注意

- 現在の構成銘柄ファイルが検証されるまで、既存の年次成績は隔離対象です
- `yfinance`は公式取引所データではありません
- 過去データ最適化は過学習しやすく、実運用成績を保証しません
- 本プロジェクトは投資助言ではありません
